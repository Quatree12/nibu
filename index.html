CONFIDENTIALITE ET LIMITES

  • Aucun compte utilisateur, aucun serveur, aucune requete reseau : tout est calcule dans ton navigateur.
  • Aucun traceur publicitaire, aucune analyse d usage, aucun cookie tiers.
  • NIBU ne te demandera jamais de mot de passe bancaire, de numero de carte ni d identifiant de compte.
  • Les donnees locales ne sont pas chiffrees et ne se synchronisent pas entre appareils. Le localStorage n est pas un coffre-fort.
  • Si tu effaces les donnees de ton navigateur sans avoir exporte, tes capsules seront perdues.
  • NIBU ne lit pas tes comptes bancaires : les depenses de la V1 sont saisies a la main.
  • Aucune notification systeme n est simulee dans la V1 : les echeances sont visibles dans l application.

CE QUE LA V1 FAIT — ET CE QU ELLE NE FAIT PAS

Fonctionne dans cette webapp

  • Afficher NIBU et son humeur dans la page.
  • Enregistrer et gerer les capsules.
  • Calculer le budget hebdomadaire en CHF.
  • Suivre rendez-vous et commandes manuellement.
  • Conserver les donnees dans le navigateur.
  • Exporter et effacer les donnees.
  • Interface responsive, installable comme raccourci web si le navigateur le permet.

Necessite une app iOS native

  • Veritable widget installe sur l ecran d accueil iOS.
  • Partage fiable des donnees entre l application et le widget.
  • Notifications locales selon les autorisations iOS.
  • Integration native au calendrier Apple.
  • Acces a des donnees d autres applications.
  • Synchronisation securisee entre plusieurs appareils.
  • Actualisation permanente en temps reel du widget.

Pour la future version native : SwiftUI avec WidgetKit. Le widget pourra afficher NIBU, la prochaine echeance, le budget restant et une commande en cours ; les interactions complexes ouvriront l application principale. Le widget respectera les mecanismes de rafraichissement d iOS.
